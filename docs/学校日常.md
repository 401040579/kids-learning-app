# 学校日常（本机 MVP）

入口：首页第一屏「🎒 学校日常」。分为「今天与书包」「阅读记录」和家长确认后出现的「家长设置」。英文界面为 School day。学校日期固定使用 `America/Los_Angeles`，与设备时区无关。

这是可编辑的通用模板，未核验学校原始 PPT。发布代码没有真实儿童姓名、学校名称或阅读记录。默认周一带充电 iPad/PE、周二还图书、周三短日无 snack；假期和家长会完整日期由家长按真实通知填写。食物默认提示避免 nuts / eggs，可编辑。没有自动预约、发信或后台推送。

## 行为契约

- 中文、英文每天各约 10 分钟；英文书籍与家中 iReady Reading 合计，Math 不计入英文阅读。不增加积分、不扣分、不产生补做债务，optional homework 保持可选。
- 补记和计时都需确认实际时间，不声称读完或理解。记录分孩子自报和家长核对；孩子只补记当天，家长可修正历史日期、活动、书名和分钟数。
- 离开面板、切换栏目或锁屏暂停计时；崩溃后仅恢复已保存的 elapsed，不补计离开后的墙钟差。跨午夜草稿保留起始 Pacific 日期。结束只生成草稿，不自动生成记录；分钟数 1–120，未满一分钟不会自动补成一分钟。
- iReady 每科每周约 45 分钟包含校内时间。家长核对校内周总量：留空为未知，0 为确认没有，不推算缺口或强制补足。不分配到某天的英文阅读，不与家中明细重复计数。
- 书包面向下一上学日，跳过周末和包含两端的假期。每天 folder/水瓶，按星期追加 iPad、PE、还书；按日期和事项去重，可取消勾选。
- 家长检查 folder、设备电量和食物，周五 newsletter，月末最后学校日准备阅读列表、次月首个学校日提示交上月表。实际截止日以学校通知为准；家长会年份/日期未确认，不预填。接送、家长会等提醒提前七天在面板显示，缺勤从前一天显示并提示按学校要求抄送老师，不代发。
- 月度列表只列有效书籍记录，iReady 不生成书名。家长可预览/打印、修正、撤销、恢复；不自动把绘本打开历史或短课估算分钟算入学校日志。
- Clever 仅为官方固定入口，无凭据保存、自动登录或抓取进度。

## 隐私与持久化

`SchoolDayStore` 使用 `AppStorage.native`，键为 `kids-learning-account:<owner>:school-day-local-v1`，游客也有独立前缀。最多12个本机档案，每档案最多5,000条记录、100条提醒和100段假期。不使用 `AppStorage.setItem`、`profileChanged`、学习事件、积分、Bark、AI 或机器人接口，不触发云 dirty。

学校数据**有意不登记到普通 `DataBackup.keys()`**，不进入普通完整备份、账号云备份或整体云恢复。家长设置提供当前学校档案单独 JSON 下载与恢复；恢复添加新档案，保留已有档案并移除未确认计时。文件应保存在私人位置；清除浏览器数据会丢失未备份记录。存储失败不覆盖旧数据、不显示成功、不淘汰作品；损坏原文保留，拒绝写入。

每次操作重读磁盘，写前检查账号、档案和冻结状态；恢复在文件读取后再次检查账号、档案与角色。同 ID 相同内容去重，不同内容拒绝覆盖。现有 AppStorage Web Lock 阻止同账号多标签页同时使用；不支持 Web Locks 的旧浏览器采用重读和 storage 事件刷新，但 localStorage 没有跨进程事务保证。

打开面板暂停 Analytics 自定义事件和该 GA property 自动收集，关闭后恢复。活动不产生新的联网操作；现有账号心跳可能继续，其允许表不含学校记录。Clever 外链和主动下载/打印不携带学校记录。

家长入口是会话操作确认，**不是身份认证或密码**。切换档案、关闭面板或切换账号回到孩子模式；同源本机存储不加密，不能替代共用设备访问控制。按原账号规则，离线冷启动未验证会话时使用游客档案；联网登录后回到该账号本机记录，不搬入游客记录。

## 可追溯验证

基准 `79d7057ba7add201d9d147db3e442550f673b08b`。两轮由当前执行代理自查，未使用独立审查代理：首轮检查存储/日期/报告契约，第二轮沿按钮、失败写入、计时、异步导入、切号和 SW 复核。没有假称核验原始学校材料。

| 发现 | 决策与修复 | 验证 |
| --- | --- | --- |
| F-01 学校资料沿用学习键会进入云和机器人流 | 独立 native 账号/档案键，单独导出，暂停 Analytics | 云备份恢复隔离、网络无私密测试标记、事件不入 dataLayer |
| F-02 打开绘本/计时或校内未知不能证明完成 | 显式确认、来源标签、null 与0分开，iReady不生成书名 | 合计/月度过滤、表单确认、家长修正撤销 |
| F-03 设备时区、周末/假期/月界可能生成错误清单 | Pacific、下一学校日、首末学校日 | UTC午夜、DST、假期、跨月回归 |
| F-04 失败重试可能丢失或重复计入 | 新鲜读、单键原子写、固定ID、失败留输入 | 配额失败重试、双击、离线重载去重 |
| F-05 迟到导入/切号可能写入旧上下文 | 文件读取后复核 owner/profile/role，冻结拒绝写 | 实际账号登录退出、延迟导入后退出家长模式 |
| F-06 部署后旧 PWA 壳仍缓存 | v84→v85，预缓存学校 JS/CSS | 旧 shell 更新按钮升级、离线冷启动 |
| F-07 崩溃时间误算、英文按钮默认中文 | 恢复不补墙钟差、英文入口绑定 book-en、跨午夜刷新 | 中断计时回归、真实英文入口与计时确认 |

逻辑回归：`node --test tests/*.test.cjs`。学校浏览器：`NODE_PATH=<Playwright node_modules> LEARNING_TEST_PYTHON=<测试 Python> SCHOOL_EVIDENCE_DIR=<私人证据目录> node tests/browser-school-day.cjs`。使用临时 SQLite、合成账号、环回服务、Chrome 手机模拟与320/390/768宽度、真实 SW；总时限180秒、单步8–15秒。图片、打印和 JSON 证据在仓库外。
